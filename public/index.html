最初にやること

友人に触ってもらう段階では、全部を埋める必要はありません。まず 3 つだけ入れれば十分です。

初回ガイド
  1. 固定予定かタスクを 1 件追加今日の判断が空にならないように、授業・課題・生活タスクのどれかを先に 1 件入れます。
  2. 自習場所を登録大学図書館や県立図書館を入れると、今日使える場所を AI にも渡せます。
  3. 必要なら Google 連携予定を読みたいときだけ接続します。ローカル運用だけでも使えます。

アプリ設定

当日入力とは分けて保持したい値です。

朝モード: 重いタスクを先に取りにいきます。
再設計モード: 崩れた日の立て直しを優先します。
夜モード: 短い必須タスクと翌日の初手を優先します。

自習場所

大学図書館や県立図書館など、対象日に使える場所と開館時間を管理します。公式URLから確認して、その日の確認結果を素早く記録できます。

自習場所を追加 / 編集
営業時間は「09:00-21:00」または「休館」で入力します。

一覧の「公式」で公式サイトを開き、「確認済 / 休館 / 短縮」で対象日の確認結果を残せます。

Cloudflare Worker 側の secret が入っていれば、Googleで接続するだけで使えます。

資格情報の入力欄は出しません。接続に必要な値は Cloudflare Worker secrets と cloudflare-worker/wrangler.toml に設定します。

OAuth 同意画面用の公開ページ: プライバシーポリシー / 利用規約

Google OAuth 公開前チェック
  • Google Cloud Console の OAuth 同意画面に、上の 2 ページの URL を登録する
  • 承認済みドメインと redirect URI を Cloudflare Worker の URL に合わせる
  • 公開前は test users に自分の Google アカウントを追加する
