# Day Manager 簡易マニュアル

対象バージョン: v0.7.0

## 毎日の基本手順
1. 対象日を確認する
2. 睡眠時間・体力・メモを更新する
3. 予定・タスクを必要分だけ直す
4. 自習場所を公式サイトで確認し、その日の状態を記録する
5. AI用文章を生成して ChatGPT / Gemini に渡す
6. 提案を見て、必要なものだけ採用する

## どこを見るか
- 今日: 現在地、危険アラート、空き時間
- 実行: 予定とタスクの一覧
- カレンダー: 日付と予定の確認
- 大学学習管理: 科目・教材・締切
- 管理・設定: 自習場所、バックアップ
- AI・連携: ChatGPT / Gemini / Google 連携

## 困ったとき
- 反映されない: Ctrl + Shift + R
- まだ古い: Service Worker / Cache Storage を削除
- 図書館情報が怪しい: 公式サイトを見て確認状態を更新
