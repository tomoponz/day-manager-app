# Day Manager 詳細マニュアル

対象バージョン: v0.7.0

## 目的
予定・タスク・体調・学習情報・自習場所を一か所に寄せ、今日の判断を短時間で固める。

## 主要機能
- 今日の判断
- 実行一覧
- カレンダー
- 大学学習管理
- 自習場所管理
- AI・連携
- バックアップ / 復元
- バージョン表示と更新バナー

## 自習場所
- 基準営業時間
- 例外日
- 公式URL
- 選択日ごとの確認記録
- 移動時間
- 優先候補

## 科目管理
- シラバス要約
- シラバス URL
- manaba / 授業ページ URL
- 授業情報
- 評価方式
- 危険度

## AI運用
AI は draft-only。予定確定や Google 反映は人間が行う。

## 更新反映
- 更新バナーが出たら再読込
- だめなら Ctrl + Shift + R
- まだ古ければ Service Worker / Cache Storage を削除
