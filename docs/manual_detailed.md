# Day Manager 詳細マニュアル

対象バージョン: v0.7.0

## 1. アプリの目的
Day Manager は、予定・タスク・体調・学習情報・自習場所を 1 か所に寄せ、今日の判断を短時間で固めるためのアプリです。

設計の前提は次の通りです。
- 人間は状態変化と制約を入力する
- アプリは現在地点を整理する
- AI は提案まで行う
- 採用・確定・Google 反映は人間が行う

## 2. 画面構成
### 今日
- いまの状態
- 危険アラート
- 今日切る候補
- 対象日の予定
- 48時間以内の締切
- 未完了タスク
- 残り空き時間
- 対象日の自習場所候補
- 最優先3件 / 時間割候補

### 実行
固定予定・単発予定・タスクを一覧で処理する画面です。  
着手 / 完了 / 明日に回す / 編集 / 削除を、一覧から直接行えます。

### カレンダー
- 月 / 日 / 一覧表示
- 対象日の予定確認
- 予定詳細表示
- 単発予定の編集導線
- Google 予定との見比べ

### 大学学習管理
- 科目
- 教材と進度
- 締切マップ
- 危険度ランキング
- 学習状況の要約

### 管理・設定
- 初回セットアップ
- 時間防衛ルール
- 自習場所
- バックアップ
- 追加と編集

### AI・連携
- AI運用方針
- クイックリンク（ChatGPT / Gemini / 大学ポータル）
- AI 用文章生成
- Google Calendar 連携
- マニュアル導線

## 3. 最初のセットアップ
### 3-1. まず入れるべきもの
最初は全部埋める必要はありません。  
次の順で十分です。
1. 固定予定を 1〜3 件
2. タスクを 1〜3 件
3. 自習場所を 1 件
4. よく使う AI リンクを設定
5. 必要なら Google Calendar 連携

### 3-2. 固定予定
授業・通学・食事など、毎週くり返す予定です。  
空き時間計算や今日の判断の土台になります。

### 3-3. 単発予定
面談・提出・外出・締切など、特定日だけの予定です。  
Google 連携を有効にすると、ローカル保存と同時に Google へ追加できます。

### 3-4. タスク
課題・復習・生活タスクを管理します。  
重要度・優先度・見積時間・締切・状態を持たせることで、判断の質が上がります。

## 4. 今日の判断の使い方
### 4-1. 先に体調を入れる
- 睡眠時間
- 体力 (0-10)
- メモ

これを入れないと、AI もアプリも「いま重いことをやるべきか」を正しく判断しにくくなります。

### 4-2. 先に見るべき場所
優先順位は次の通りです。
1. 危険アラート
2. 48時間以内の締切
3. 残り空き時間
4. 対象日の自習場所候補
5. 最優先3件

### 4-3. AI の使い方
「今日を設計する文章を生成」を押すと、今日の情報をまとめた文章が作られます。  
それを ChatGPT や Gemini に渡して、提案を受けます。

重要: **AI は draft-only** です。  
AI の提案は参考にするが、確定・採用・Google 反映は人間が行います。

## 5. 自習場所の使い方
### 5-1. 持てる情報
- 場所名
- 種別（大学図書館 / 県立図書館 / 市立図書館 / カフェ / 自宅 など）
- 移動時間
- 公式 URL
- 曜日別営業時間
- 例外日
- メモ
- 優先候補フラグ
- 日付ごとの確認記録

### 5-2. 実際の運用
完全自動取得は前提にしていません。  
代わりに、朝に公式 URL を開いて確認し、**その日の状態だけ記録**します。

使い分けはこれです。
- **確認済**: 通常どおり使える
- **休館**: その日は候補から落とす
- **短縮**: 閉館時刻を考慮して候補に入れる

### 5-3. なぜこの方式か
図書館サイトは館ごとに形式が違い、自動取得は壊れやすいからです。  
Day Manager では、**手動確認 + 当日記録** を前提にしています。

## 6. 学習管理の使い方
### 6-1. 科目
科目ごとに以下を持てます。
- 科目名
- 教員
- 単位数
- 授業情報
- 評価方式メモ
- 危険度
- シラバス要約
- シラバス URL
- manaba / 授業ページ URL
- メモ

### 6-2. 教材
教科書・配布資料・問題集・動画などの進度を管理します。  
進捗、理解度、次にやる場所を残すことで、再開コストを下げます。

### 6-3. 締切マップ
試験・レポート・小テスト・宿題などを科目に紐づけて整理します。  
「締切が近いのに進度が悪い科目」を危険度ランキングに反映できます。

## 7. Google Calendar 連携
### 7-1. 何ができるか
- 対象日の Google 予定を読む
- ローカル単発予定を Google に追加する
- Google 側の予定と app 側の予定を見比べる

### 7-2. 注意
- 連携は β 扱いです
- OAuth 設定が未公開段階では、test users 運用が安全です
- 友人に使ってもらう場合は、使う Google アカウントを事前に確認してください

## 8. バックアップと更新
### 8-1. バックアップ
- バックアップ書き出し
- バックアップ読込
- 直前状態を復元

削除や大きい読込の前には自動退避が入る前提です。

### 8-2. 更新が反映されないとき
1. 更新バナーが出たら再読込
2. `Ctrl + Shift + R`
3. まだ古ければ Service Worker / Cache Storage を削除
4. Cloudflare Worker 配信中なら `npm run deploy`

## 9. 友人向けの共有手順
1. 公開 URL を送る
2. 使う Google アカウントを事前に確認する
3. test users 運用中なら、対象アカウントを追加しておく
4. 最初は Google 連携なしでも使えることを伝える
5. AI 提案は参考であり、確定は手動で行うことを伝える

## 10. よくある質問
### Q. まず全部登録した方がいいですか？
いいえ。固定予定かタスクを数件入れるだけで十分です。

### Q. Google 連携は必須ですか？
必須ではありません。ローカルだけでも使えます。

### Q. 図書館情報は自動で取れますか？
現状は手動確認前提です。公式 URL を開き、その日の確認状態を更新してください。

### Q. AI が提案した予定は自動で反映されますか？
反映されません。Day Manager は draft-only 方針です。

### Q. 更新したのに古いままです
Service Worker のキャッシュが残っている可能性があります。再読込とキャッシュ削除を試してください。
